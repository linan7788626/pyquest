## 意图与为什么

用户反馈：当前地面"朴素"，不像 NLI 新素材。根因（已核实）：游戏地面是程序化合成画布——实心底色 + NLI 材质以 0.32→0.62 半透明叠加 + 网格线 + 程序化波线/边缘蒙版。NLI 材质只作"颜料层"，且源包最有辨识度的**整块立体地形**（带崖面）从未进入运行资源。

用户选择的方向（"前者"，2026-10-29 对话确认）：**直接渲染 NLI 原生整块软绘地形，带沿水边/地图边界自动生长的立体崖面**；角色走到崖壁后方被崖面遮挡。原型已验证可行与观感（`.scratch/nli-terrain-spike/`，throwaway 脚本 `build_spike.py`，产物 village-spike.png / village-spike-detail.png / comparison.jpg，用户过目后批准立项）。

## 目标

1. 户外场景（Village 先行，其余户外野外场景跟进）的地面由 NLI 原生地形块拼成：草/路/水/花田为原生材质整片，不再是底色+半透明纹理。
2. **自动崖面**（零手工高度数据，全部从网格邻接推导，位序沿用 ground.js adjacentMask：W=1,E=2,N=4,S=8）：
   - 南邻水/边界 → 正面崖（草唇+岩壁+基岩+浪花，原生切片；崖体高 FH≈104px：8px 草唇压陆格 + ~96px 伸入下方水格）**（已于 2026-10-30 修订，见下方修订块）**；
   - 东西邻水/边界 → 原生侧壁窄条；
   - 北邻水/边界 → 草唇外沿 + 合成阴影带（**素材缺口**：该画风无北向崖面，属已知约定，非缺陷）。
3. 深度遮挡：崖面绘制晚于实体 → 崖前（北）实体下半身被遮（y 排序语义与现有树/建筑一致）。
4. 显示层调色：原生素材草色偏荧光黄绿，向游戏现有橄榄绿/深蓝基调收敛（调色在显示层，源素材像素不改）。
5. 玩法零变化：碰撞网格、移动速度 1120、攻击 280/340ms、抽题、双语、存档语义全部不动。

## 非目标

- 不做北向崖面原生素材（缺素材，用唇+阴影约定）。
- 高度不影响玩法（纯视觉层，无跳跃/阻挡变化）。
- 室内场景（Dungeon/Cave/C5F…C8L 等 indoor profiles）本期不重构，保持现有材质合成（可只受益于调色经验，不换结构）。
- 不加手工高度编辑器或高度数据。

## 反目标（即便技术上跑通也算失败）

- 静默改变碰撞/地图几何导致 4 个 fixtures 或 94 张 before 快照在未显式声明契约变更的情况下挂掉。
- 原生荧光色直出（原型证明必须调色）。
- 合成/近似处不标注、冒充原生（诚实约定）。
- 单场景地面纹理生成导致明显卡顿或内存膨胀（现状是每场景一次性生成+缓存，需保持同数量级）。

## 已定的实施方式（对话+原型+builder-check 确认）

- 崖面规则与切片来源：正面崖 = `Island_Cliff_Composition` 切片（脚本实测坐标：顶面 y≈226..430、正面崖 y≈430..880、基岩+浪花 y≈880..1100；正面崖整条 src=(350,405,900,915)）；材质 = `Terrain_Samples`。
- **画布与世界边界零外扩（用户确认）**：画布/世界 bounds/相机 clamp 保持各场景现值（Village 4608×3072）不变，fixtures 零触碰。崖面**只长在陆格邻水侧**（崖体伸入南侧水格 ~96px，天然在画布内）；陆地干边界不长崖（Phase 2 若有需求另行立项走显式契约变更）。
- **合成元素一并原生化（用户确认）**：花田贴片、城堡土垫（VILLAGE_GROUND_PADS）、门口铺路在 Phase 1 内改为原生素材替代或删除（无原生对应物时如实记录替代方案）；接受随之扩大的导出 manifest / KEYS 列表 / 质量门 / 测试改动面。
- 调色策略：显示层收敛（原型用 ImageEnhance/调色带，游戏内为 canvas 全局滤镜或逐块调色，由实施者选并记录）。
- 分期：**Phase 1 Village 试点**（全部崖面方向、遮挡、调色、合成元素原生化、契约更新、专项断言）；**Phase 2 其余户外场景**（Forest/SciField/C4F/C7F 等 outdoor profiles，按同一规则批量）；室内不动。
- 自动推导扩展点：内角/双面崖（一格南+东都邻水）处理；门口铺路原生化方案。

## 留给实施者的

- 游戏内纹理策略：每场景一次性合成大画布（沿用现有缓存架构）vs 分层（地面画布 + 独立崖面 sprite 层参与 y 排序）——两方案取舍与性能验证（画布尺寸已定不外扩）。
