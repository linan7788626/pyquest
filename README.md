# PyQuest · Python 冒险记 ⚔️

一款**用塞尔达式动作冒险学习 Python 基础**的网页游戏。
画风致敬《塞尔达传说：织梦岛》Switch 重制版 + 欧美 Q 版卡通：俯视角、大头小身比例、
描边卡通渲染（帽子/羽毛/肩带/宝珠等层叠细节）、柔和粉彩配色、无像素马赛克的矢量渲染。
**全部角色以 4 倍尺寸显示**（`src/core/scale.js` 一键调节），环境物件按 2.5 倍跟随缩放。
美术采用 **CC0 公共领域像素素材**（0x72 DungeonTileset II + Kenney Tiny Town，可自由商用与再分发）
+ 少量同风格程序化贴图（符文石/碎片/传送门等游戏专属元素）。

## 🗺️ 游戏流程

### 第一章 · 循环地牢（变量 / 输出 / 条件 / 循环）
1. **诺瓦村庄**：和长老对话了解背景；挥剑击败游荡的史莱姆（掉落爱心）。
2. **符文石谜题**：找到 **5 块符文石**，回答 Python 问题（选择题 + 代码填空）：
    - 变量与赋值、字符串引号、类型错误、整除与取余
    - **题目从同难度题池中随机抽取**——每次冒险遇到的题目都可能不同，但难度保持一致
    - 答对获得 **代码碎片**，答错扣 1 颗心并可重试
3. **北方石门**：集齐 5 枚碎片开门，进入**循环地牢**。
4. **循环地牢**：火把照明、更多史莱姆、输出/条件/循环进阶符文石 +
   **4 块祝福符文**（答对回 1 颗心，不产碎片）。
5. **循环史莱姆王**：紫色护盾免疫一切伤害 —— 必须答对 `for / range` 循环谜题破盾，
   破盾后才能造成伤害；BOSS 会在残血时召唤帮手。
6. 击败 BOSS → 第一章结算 → **村庄东侧开启森林传送门**。

### 第二章 · 函数之森 & 列表洞窟（函数 / 列表）
1. **函数之森**：阅读函数石碑了解 `def`；森林里有更快的**蓝史莱姆**（3 HP）。
2. **函数符文 ×5 + 祝福符文 ×1**：`def` 定义、参数传递、`return`、默认参数、
   局部作用域 → 集齐 **5 枚函数碎片**。
3. **洞窟封印**：集齐 5 枚碎片后按 E 解开北方封印，进入**列表洞窟**。
4. **列表符文 ×6（祝福）**：索引、`append` / `len`、修改元素、切片、`in` 成员判断、
   字典与元组入门 —— 答对全部回心，不产碎片。
5. **列表巨蟒 毕森**：身体是一条会动的「列表」（头 + 6 节体节）。答对 BOSS 符文
   破除符文护盾后，攻击头部才会造成伤害；每损失 2 HP 断掉一节尾巴并提速，
   还会蓄力后向前突咬。
6. 封印巨蟒 → **全部通关**！结算显示用时与解开的谜题数。

## 💾 存档系统

- 进度**自动保存**到 `localStorage`（键 `pyquest:save:v1`）：
  生命、两章碎片、已解符文槽、已答题目与符文抽题记录、门/封印状态、BOSS 血量阶段、章节标记。
- 标题画面会显示 **「继续冒险」**（读档继续，按进度落在对应章节）；
  「新的冒险」覆盖存档重新开始（有确认提示）。
- 通关结算中的「重新开始」会清档重置。
- 存档实现：`src/core/save.js`（任何 HUD 数据变化 / 关页 / 切后台时写档）。

## 📖 知识点覆盖（61 题 · 7 个同难度题池 · 本科 Python 课标基础）

每块符文石从所属**同难度题池**随机抽题：同池题目 `tier` 一致，
随机但不撞题（同池多块符文不重复、已答过的题不再出现），
同一块符文石在答对之前始终是同一道题。

| 题池 | 题量 | 知识点 |
| --- | --- | --- |
| 村庄（第一章 · 碎片） | 13 | 赋值、变量复制与重赋值、命名规则、`type`、字符串引号/拼接/重复、`str + int` 报错、优先级、`**`、`//` 与 `%`、比较 |
| 地牢（第一章 · 祝福） | 11 | `print` 多参数、f-string、`if / elif / else`、`!=`、`and / or / not`、`while + break`、`while` 递减、`for` 遍历列表、`range(起, 止)` |
| 史莱姆王 BOSS | 4 | `for + range` 次数、循环累加、`range` 起止、字符串累积 |
| 函数之森（第二章 · 碎片） | 11 | `def`（填空）、参数传递、`return`、默认参数、局部作用域、多次调用、多参数、`return` 中断、覆盖默认值、参数数量、`return` 更新外部变量 |
| 森林祝福 | 4 | 元组不可变、元组索引、解包、单元素逗号 |
| 列表洞窟（第二章 · 祝福） | 14 | 索引/负索引（填空）、`append` / `len` / `pop`、修改元素、越界、切片、`in` 成员与字典键判断、列表相加、`sum`、字典存取与更新 |
| 巨蟒 BOSS | 4 | 列表 `append` + 索引综合、循环生长 `len`、索引覆盖 |

## 🎨 画面技术（Tiny Swords 素材 + CC0/程序化补充）

- **主素材**：[Tiny Swords](https://pixelfrog-assets.itch.io/tiny-swords)（Pixel Frog · Free Pack，
  本地 `assets/TinySwordsFreePack/`，**许可证禁止再分发 → .gitignore 排除，需自行下载**）——
  角色全套（蓝勇士/僧侣/红小兵/黑勇士/紫勇士）、tileset 地形、树/灌木/云/岩石/民居、
  尘土/火焰/水花/爆炸/泡沫特效
- **CC0 补充**（`assets/cc0/`，随仓库分发）：
  - [0x72 DungeonTileset II v1.7](https://0x72.itch.io/dungeontileset-ii)（`assets/cc0/0x72/`）——
    骑士主角（待机/奔跑动画）、红鬼/绿萨满小怪、大恶魔 BOSS、鼻涕虫巨蟒、
    石柱/宝箱/大门等地牢元素
  - [Kenney Tiny Town / Tiny Dungeon](https://kenney.nl/assets/tiny-town)（`assets/cc0/kenney/`）——
    草地/花地/土路 tileset、树木、火盆
  - **TS 坐标系**：逻辑 tile 64px（相机 1x、单位帧 192×192 原尺寸 1:1 渲染，像素完美）
- 角色映射：勇者=蓝军勇士（待机/奔跑/挥剑动画）、长老=蓝军僧侣、村庄小怪=红小兵、
    森林小怪=黑勇士、第一章 BOSS=紫勇士巨型化+金徽（循环之王）、巨蟒=黑勇士头+黑小兵体节
- 符文石待解状态仅做 ±0.7% 微缩放呼吸（视觉跳动 < 1px），不干扰辨识
- **像素完美渲染**：16px tile × 相机 4x 整数放大，`pixelArt: true`，无插值模糊
- **地形拼接**：`ground.js` 把 tileset 拼成整图画布——野外用 Kenney 草/土路
  （邻接草色咬边），水面按 Kenney 平涂+深紫描边风格自绘（含岸线/浅水带/波纹），
  地牢用 0x72 石地 + **亮顶/暗面立体砖墙**，洞窟叠紫调
- **房屋拼合**：`assets/cc0.js` 把 Kenney 瓦/墙/窗/门 tile 拼成 128×96 小屋
- **程序化补充**（`textures/pixelArt.js`）：符文石/代码碎片/爱心/传送门/函数石碑/
  水晶/蘑菇等游戏专属元素，与素材同风格（平涂 + `#3f2631` 深紫描边）
- **碰撞与渲染分离**：碰撞由不可见静态矩形承担（`WorldScene.tileBodies`）

## 🔧 如何扩展

- **加题**：在 `src/data/quizData.js` 的 `QUESTIONS` 里加一条
  （支持 `options` 选择题或 `fill: true` 代码填空，记得标 `tier` 难度），
  然后把题目 id 加进对应的 `POOLS` 题池——该池的符文石就会随机抽到它
  （`SLOT_POOL` 已把地图里的符文槽 `qid` 映射到题池，无需改地图）。
- **改地图**：`src/data/maps.js` 是纯代码构建器，改数字即可挪动池塘、道路、道具。
- **加场景**：继承 `WorldScene`，提供 `mapDef` 即可获得全部系统（交互/传送/HUD）。
